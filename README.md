# 수행평가 알리미 — 충주대원고

충주대원고등학교 2026학년도 1학기 교수학습 및 평가계획을 바탕으로, 수행평가 일정을 주차별로 관리하고 마감 전에 알려주는 웹 플래너입니다.

**사이트:** https://htw01097057323-cpu.github.io/daewon-suhaeng/

## 기능

- **오늘** — 가장 가까운 수행평가, 마감 임박·남은·지난 건수(각각 더보기 팝업)
- **월별 달력** — 여러 날에 걸친 평가를 구글 캘린더처럼 막대로 표시, 주별 더보기
- **주차별 계획** — 한 달을 1주차~N주차로 나눠 각 주의 일정을 확인하고 추가
- **전체 일정** — 검색, 과목·학년 필터, 지난 일정 표시
- **일정 관리** — 직접 추가·수정·삭제, JSON 내보내기/가져오기, 기본 계획 복원
- **알림** — 마감 N일 전부터, 지정한 간격(시간/일) 또는 매일 정해진 시각, 야간 제외

일정 데이터는 각자의 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (HTML·CSS·JS·데이터 단일 파일) |
| `sw.js` | 서비스 워커 — 알림 표시, 오프라인 캐시, 푸시 핸들러 |
| `manifest.webmanifest` | 홈 화면·앱 설치용 |
| `icon.svg` | 앱·알림 아이콘 |

## 알림에 대해

- https로 접속해야 브라우저가 알림 권한을 기억합니다. 파일을 직접 열면(`file://`) 권한이 저장되지 않습니다.
- 모바일에서는 브라우저 메뉴의 **홈 화면에 추가**를 하면 더 안정적으로 알림을 받습니다.
- 브라우저 알림이 차단돼 있어도 화면 오른쪽 아래 알림 카드로 대신 알려줍니다.
- 정적 사이트라 **브라우저를 완전히 종료하면 알림이 오지 않습니다.** 닫아도 알림을 받으려면 푸시 서버(VAPID) 연결이 필요하며, `sw.js`에 `push` 핸들러를 미리 넣어 두었습니다.

## 학년 표기에 대해

학교 홈페이지 교수학습센터 게시글에는 학년 구분이 없고 HWP 첨부 안에만 있습니다. 그래서 과목의 이수 학년은 교육과정 체계로 판단했습니다.

- 2022 개정 공통과목(공통국어1, 통합사회1 등) → 1학년
- 2022 개정에만 있는 선택과목(대수, 미적분Ⅰ, 물리학 등) → 2학년
- 2015 개정에만 있는 과목(화법과 작문, 사회문화, 물리학Ⅱ 등) → 3학년
- 두 교육과정에 같은 이름으로 있는 과목은 **(추정)** 으로 표시

일정 수정 창에서 학년을 직접 지정하면 그 값이 우선합니다.
